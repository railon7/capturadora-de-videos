# Glosario ES-EN

Un término preferido por concepto, en español y en inglés. Los documentos de la biblioteca usan estos términos.
Los nombres de pantallas y botones de una aplicación se traducen como los llama su interfaz en ese idioma, no como esta tabla.

## Términos

| Español | Inglés | Definición | Notas |
|---|---|---|---|
| Manual de aplicación | Application manual | Describe cómo es una aplicación y qué hace cada parte. Común, sin datos de cliente. | Tipo MAN |
| Guía de usuario | User guide | Resuelve una tarea concreta de quien ya sabe usar la aplicación. | Tipo GUI |
| Procedimiento normalizado de trabajo (PNT) | Standard operating procedure (SOP) | Procedimiento con control: quién, cuándo y qué registro deja. | Tipo SOP. En España se usa PNT sobre todo en sanidad y calidad |
| Tutorial de formación | Training tutorial | Lección guiada con un resultado visible. | Tipo TUT |
| Guía rápida | Quick-start guide | Una página: objetivo y cinco pasos como máximo. | Tipo QSG |
| Preguntas frecuentes | Frequently asked questions (FAQ) | Preguntas repetidas con su respuesta corta. | Tipo FAQ |
| Resolución de problemas | Troubleshooting | Síntoma, causa probable y solución. | Va dentro del tipo FAQ |
| Notas de versión | Release notes | Qué cambia en una versión de una aplicación. | Tipo NOV |
| Registro de decisión | Decision record | Por qué se decidió algo, con alternativas y consecuencias. | Tipo DEC |
| Patrón reutilizable | Reusable pattern | Lección que ya no es una anécdota de un solo proyecto. | Tipo PAT |
| Biblioteca de conocimiento | Knowledge library | Conjunto ordenado de documentos con sus metadatos. |  |
| Borrador | Draft | Se está escribiendo. | Estado `borrador` |
| En revisión | In review | Lo revisa otra persona. | Estado `revision` |
| Aprobado | Approved | Validado por un revisor, versión 1.0 o superior. | Estado `aprobado` |
| Obsoleto | Obsolete | Ya no vale. Se archiva, no se borra. | Estado `obsoleto` |
| Propietario | Owner | Quien responde del documento. |  |
| Revisor | Reviewer | Quien lo valida antes de aprobarlo. |  |
| Historial de cambios | Change history | Tabla de versiones al final del documento. |  |
| Captura de pantalla | Screenshot | Imagen de una pantalla de la aplicación. | Siempre tapada y anotada antes de publicar |
| Paso | Step | Una acción con una sola decisión. |  |
| Aplicación | Application | El programa o sistema que describe el documento. | También se dice "software" o "sistema" |
| Albarán | Delivery note | Documento que acompaña a la mercancía entregada. |  |
| Presupuesto | Quote | Oferta de precio antes del pedido. | No confundir con el presupuesto contable (budget) |
| Pedido | Order | Compromiso de compra o de venta. | De compra: purchase order |
| Factura rectificativa | Corrective invoice | Factura que corrige otra ya emitida. | Si reduce el importe se llama también credit note |
| Asiento contable | Journal entry | Anotación en el libro diario. |  |
| Plan de cuentas | Chart of accounts | Listado de cuentas contables de una empresa. | En España, basado en el Plan General Contable (PGC) |
| Subcuenta | Sub-account | Nivel de detalle de una cuenta, por ejemplo cada cliente. |  |
| Contrapartida | Offsetting account | Cuenta que recibe la otra parte del asiento. |  |
| Libro de IVA | VAT ledger | Registro de facturas emitidas y recibidas con su IVA. |  |
| Retención | Withholding | Importe que se retiene a cuenta de un impuesto. |  |
| Cierre de ejercicio | Year-end close | Proceso contable que cierra un año fiscal. |  |
| Modelo 347 | Form 347 | Declaración anual de operaciones con terceros. | Mantener el término español: es un modelo de la Agencia Tributaria |
| SII | SII (Immediate Supply of Information) | Suministro Inmediato de Información del IVA a la Agencia Tributaria. |  |
| NIF / CIF | Tax identification number | Identificador fiscal de personas y empresas. | Dato personal: no puede salir en capturas |
| DNI | National ID number (DNI) | Documento nacional de identidad. | Dato personal: no puede salir en capturas |
